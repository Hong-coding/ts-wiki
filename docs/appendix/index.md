# 부록

부록은 **처음부터 끝까지 읽는 곳이 아니라, 필요할 때 펼쳐 보는 곳**입니다. 레슨을 따라가다가 "이 용어가 뭐였지?", "`Partial`이 뭐 하는 타입이었지?", "이 TS 코드는 JS로 바꾸면 어떻게 되지?" 하는 순간이 오면 이곳에서 바로 찾아보세요.

## 어떻게 쓰면 좋을까요?

1. **브라우저의 찾기 기능(Windows는 Ctrl+F, macOS는 Cmd+F)을 적극적으로 씁니다.** 부록 문서는 길지만 표와 목록으로 되어 있어서, 단어 하나로 원하는 줄을 바로 찾을 수 있습니다.
2. **위키 상단의 검색창도 함께 씁니다.** 용어집에 없는 단어라도 레슨 본문 어딘가에 설명이 있을 수 있습니다.
3. **부록은 요약본입니다.** 표의 한 줄 설명만으로 이해가 되지 않으면, 각 항목 옆의 "관련 레슨" 링크를 따라가 자세한 설명과 연습 문제를 다시 봅니다.
4. **치트시트 코드는 그대로 복사해서 실행해 볼 수 있습니다.** 모든 조각을 TypeScript 5.6, `strict` 설정에서 컴파일해 확인했습니다.

아직 Part 0이나 Part 1을 공부하고 있다면 치트시트의 뒷부분(제네릭, 조건부 타입 등)은 지금 이해하지 못해도 괜찮습니다. 지금은 [용어집](./01-glossary)과 [VS Code 팁](./04-vscode-tips)부터 가볍게 훑어보고, 나머지는 해당 파트에 도착했을 때 다시 펼쳐 보세요.
:::

::: info 버전 기준
부록의 내용은 TypeScript 5.x, `strict: true` 설정을 기준으로 합니다. 이보다 새 기능에는 도입 버전을 따로 적었습니다.
:::
