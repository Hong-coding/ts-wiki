# 12주 학습 계획

**주 5일, 하루 1.5~2시간**(주 약 8~10시간)을 기준으로 한 계획입니다. 전체 레슨 학습은 약 80시간, 연습 문제 복습·프로젝트 확장까지 포함하면 100~120시간 정도 걸립니다.

::: tip 속도는 사람마다 다릅니다
계획보다 느려도 괜찮습니다. 한 주가 밀리면 다음 주로 그냥 미루세요. 중요한 것은 **주차를 건너뛰지 않는 것**입니다. 반대로 하루 4시간 이상 공부할 수 있다면 6주 계획(아래)을 쓰세요.
:::
