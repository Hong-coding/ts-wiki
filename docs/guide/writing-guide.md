# 문서 작성 규칙

이 위키의 모든 레슨은 같은 뼈대를 따릅니다. 학습자는 페이지마다 같은 순서로 읽고 연습하므로, 새 문서를 쓰거나 고칠 때 이 규칙을 지켜 주세요.

## 독자

- **프로그래밍을 한 번도 해 보지 않은 사람**이 기준입니다.
- 처음 나오는 용어는 반드시 그 자리에서 풀어 씁니다. 예: "매개변수(parameter, 함수가 받는 입력값을 담는 변수)"
- "당연히", "간단히", "쉽게" 같은 말은 쓰지 않습니다. 독자에게는 당연하지 않습니다.

## 레슨 뼈대

각 레슨 파일은 아래 순서를 지킵니다. 제목 문구는 그대로 씁니다.

```md
---
title: 레슨 제목
---

# 레슨 제목

<LessonMeta level="입문" :minutes="40" prev="이전 레슨에서 배운 것 한 줄" />

## 이번에 배울 것
- 학습 목표 3~5개 ("~할 수 있다" 형태)

## 먼저 알아 둘 것
- 선수 지식과 링크 (없으면 "없음")

## 비유로 이해하기
- 일상의 비유로 개념의 핵심을 먼저 잡습니다.

## 개념 설명
- 작은 단계로 나눠 설명합니다. 소제목(###)을 적극적으로 씁니다.
- 예제 코드 → 실행 결과 → 해설 순서를 지킵니다.

## 자주 하는 실수
- "잘못된 코드 → 왜 틀렸나 → 고친 코드" 3개 이상

## 직접 해 보기
- 연습 문제 4~6개. 난이도 표시: ⭐ 기초 / ⭐⭐ 응용 / ⭐⭐⭐ 도전
- 각 문제 바로 아래에 정답을 접어 둡니다.

## 확인 퀴즈
- 개념을 확인하는 짧은 질문 3~5개 (정답 접어 두기)

## 정리
- 핵심 요약 3~7줄

## 다음 단계
- 다음 레슨 링크와 한 줄 소개
```

## 마크다운 작성 시 주의 (VitePress 빌드 오류 방지)

VitePress는 마크다운을 Vue 템플릿으로 처리합니다. 다음을 지키지 않으면 빌드가 깨집니다.

1. **본문에서 타입 문법은 반드시 인라인 코드로 감쌉니다.** `Array<string>`, `Promise<T>`, `Record<K, V>`처럼 꺾쇠(`<`, `>`)가 들어간 표현을 맨글자로 쓰면 HTML 태그로 해석됩니다.
2. **본문에 이중 중괄호를 맨글자로 쓰지 않습니다.** 필요하면 인라인 코드로 감쌉니다.
3. 코드 블록은 언어를 반드시 지정합니다: `ts`, `js`, `bash`, `json`, `tsx`, `vue`, `text`.
4. 정답·해설은 접기 블록을 씁니다.

```md
::: details 정답 보기
정답 내용
:::
```

5. 강조 박스: `::: tip`, `::: warning`, `::: danger`, `::: info` 를 씁니다.
6. 오류가 나는 예제 코드에는 주석으로 실제 에러 메시지를 적습니다.

```ts
let age: number = '스물'
// ❌ Type 'string' is not assignable to type 'number'. (TS2322)
```

7. frontmatter `title`에 콜론(`:`)이 들어가면 YAML 오류가 나므로 작은따옴표로 감쌉니다. 예: `title: '프로젝트 1: 콘솔 가계부'` (`npm run fix:frontmatter`가 자동으로 고칩니다)
8. 내부 링크는 상대 경로로 쓰고 확장자 `.md`는 생략합니다. 예: `[함수 기초](../part1-basics/06-functions)`. 존재하지 않는 페이지로 링크하면 빌드가 실패합니다.

## 코드 예제 규칙

- TypeScript 5.x, `strict: true` 기준입니다.
- 주석은 한국어로 씁니다.
- 예제는 복사해서 그대로 실행할 수 있어야 합니다. 실행 결과는 `// 출력: ...` 주석이나 `text` 블록으로 보여 줍니다.
- 버전에 따라 달라지는 기능은 지원 버전을 밝힙니다. 예: "`satisfies`는 TypeScript 4.9부터"
- 변수 이름은 영어로, 예시 데이터는 한국 실무에 가까운 것(상품·주문·회원·매장 등)을 씁니다.
