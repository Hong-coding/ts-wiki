# Part 0. 시작하기

이 파트는 **프로그래밍을 한 번도 해 보지 않은 분**을 위한 출발점입니다. 아직 코드 한 줄 써 본 적이 없어도 괜찮습니다. 이 파트를 마치면 내 컴퓨터에서 직접 만든 TypeScript 프로그램을 실행하고, 화면에 빨간 에러가 떠도 당황하지 않고 읽어 낼 수 있게 됩니다.

## 이 파트가 왜 필요한가요?

TypeScript 문법부터 바로 배우고 싶은 마음이 들 수 있습니다. 하지만 처음 배우는 분이 가장 많이 포기하는 지점은 문법이 아니라 **문법 바깥**입니다.

- "프로그램을 실행한다"는 말이 정확히 무슨 뜻인지 모르면, 예제를 어디에 입력해야 하는지부터 막힙니다.
- 설치가 잘못되면 명령어를 입력해도 "인식되지 않는 명령"이라는 낯선 문장만 보게 됩니다.
- 에러 메시지를 읽는 법을 모르면, 사실은 오타 하나인 문제에 몇 시간을 씁니다.

그래서 Part 0에서는 **개념 → 도구 → 첫 실행 → 문제 해결** 순서로 기초 체력을 먼저 만듭니다. 이 기초가 있어야 Part 1부터 나오는 수많은 예제를 막힘없이 따라 할 수 있습니다.

## 학습 흐름

| 순서 | 레슨 | 무엇을 하나요 |
|---|---|---|
| 1 | 프로그래밍과 JavaScript, 그리고 TypeScript | 컴퓨터·프로그램·소스 코드·컴파일·런타임이 무엇인지 비유로 이해합니다. |
| 2 | 왜 TypeScript인가 | JavaScript에서 실제로 자주 나는 버그를 TypeScript가 어떻게 미리 막는지 비교합니다. |
| 3 | 개발 환경 설치 | Node.js, VS Code, Git을 설치하고 터미널 기본 명령을 익힙니다. |
| 4 | TS Playground | 설치 없이 웹 브라우저에서 바로 TypeScript를 써 봅니다. |
| 5 | 첫 프로그램 | 내 PC에 프로젝트를 만들고, 컴파일하고, 실행합니다. |
| 6 | 에러 메시지 읽는 법 | 에러 메시지를 해부하고, 검색·AI·공식 문서로 도움을 받는 법을 배웁니다. |

::: tip 설치가 걱정된다면
3번 레슨(설치)이 어렵게 느껴지면 4번 레슨(Playground)을 먼저 해도 됩니다. Playground는 웹 브라우저만 있으면 되므로, 설치 없이도 Part 1·Part 2 예제 대부분을 따라 할 수 있습니다. 다만 5번 레슨부터는 설치가 꼭 필요합니다.
:::

## 이 파트를 마치면

- "소스 코드", "컴파일", "런타임", "Node.js" 같은 말을 내 언어로 설명할 수 있습니다.
- TypeScript가 JavaScript와 어떤 관계인지, 왜 많은 회사가 TypeScript를 쓰는지 말할 수 있습니다.
- 내 PC에 Node.js · VS Code · Git이 설치되어 있고, 터미널에서 폴더를 이동하고 만들 수 있습니다.
- `npx tsc`로 TypeScript 파일을 JavaScript로 바꾸고 `node`로 실행할 수 있습니다.
- 에러 메시지에서 파일 이름·줄 번호·에러 코드를 찾아 원인을 짐작하고, 모르는 것은 제대로 질문할 수 있습니다.

## 막히면 이렇게 하세요

1. **에러 메시지를 그대로 복사해 둡니다.** 화면을 대충 보고 기억에 의존하지 말고, 한 글자도 바꾸지 않은 원문을 메모장에 붙여 넣습니다.
2. **방금 바꾼 것 하나만 되돌려 봅니다.** 대부분의 문제는 "마지막으로 바꾼 곳"에 있습니다.
3. **6번 레슨을 먼저 읽어도 됩니다.** [에러 메시지 읽는 법과 도움 받는 법](./06-how-to-read-errors)은 순서와 상관없이 언제 펼쳐 봐도 도움이 되도록 썼습니다.
4. **새 터미널 창을 열거나 컴퓨터를 다시 시작해 봅니다.** 특히 설치 직후의 문제는 이것만으로 풀리는 경우가 많습니다.
5. **처음부터 다시 따라 해 봅니다.** 단계를 하나 건너뛴 것이 원인인 경우가 생각보다 많습니다.

::: info 천천히 가도 괜찮습니다
레슨마다 표시된 학습 시간은 참고용입니다. 처음 배우는 분은 표시된 시간의 두세 배가 걸리는 것이 정상입니다. 빨리 끝내는 것보다 "왜 그렇게 되는지"를 이해하고 넘어가는 것이 훨씬 중요합니다.
:::
