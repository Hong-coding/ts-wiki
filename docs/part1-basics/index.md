# Part 1. 프로그래밍 기초 (TypeScript로 배우는 JavaScript)

Part 0에서 내 PC에 TypeScript 프로젝트를 만들고 첫 프로그램을 실행했습니다. 이제 본격적으로 **프로그래밍 자체**를 배웁니다. 값을 담고, 계산하고, 조건에 따라 다르게 움직이고, 같은 일을 반복하고, 코드를 함수로 묶는 법입니다. 이 파트를 마치면 장바구니 합계, 회원 등급별 할인, 재고 찾기 같은 작은 프로그램을 스스로 짤 수 있게 됩니다.

## 왜 JavaScript 기초를 TypeScript로 배우나요?

TypeScript는 **JavaScript에 타입을 더한 언어**입니다. `if`, `for`, 함수, 배열 같은 문법은 JavaScript와 완전히 같습니다. 그래서 이 파트에서 배우는 내용은 사실상 JavaScript 기초입니다. 그런데도 처음부터 TypeScript로 배우는 이유가 있습니다.

- **실수를 바로 알려 줍니다.** 처음 배우는 사람이 가장 많이 하는 실수(오타, 숫자와 문자열 혼동, 없는 값 사용)를 VS Code가 빨간 밑줄로 즉시 알려 줍니다. 혼자 공부할 때 옆에서 봐 주는 선배가 있는 셈입니다.
- **나중에 다시 배우지 않아도 됩니다.** JavaScript로 배운 뒤 TypeScript로 옮기면 습관을 한 번 더 고쳐야 합니다. 처음부터 타입을 의식하며 배우면 그 과정이 필요 없습니다.
- **실무와 같은 환경입니다.** 요즘 웹·서버 프로젝트의 상당수가 TypeScript를 씁니다. 연습 환경과 실무 환경이 같으면 넘어갈 때 덜 헤맵니다.

다만 이 파트에서는 타입 문법을 **최소한만** 씁니다. `: number`, `: string` 같은 간단한 표기 정도이고, 대부분은 TypeScript가 알아서 추론하게 둡니다. 타입을 제대로 다루는 법은 [Part 2](../part2-types/)에서 배웁니다.

## 학습 흐름

| 순서 | 레슨 | 무엇을 하나요 |
|---|---|---|
| 1 | 값과 변수 | `let`·`const`로 값을 담는 상자를 만듭니다. |
| 2 | 원시 타입 | 숫자·문자열·불리언·`null`·`undefined`, 값의 종류를 익힙니다. |
| 3 | 연산자와 표현식 | 계산·비교·논리 연산과 `===`, `??`, `?.`를 배웁니다. |
| 4 | 조건문 | `if`·`switch`·삼항 연산자로 상황에 따라 다르게 동작하게 합니다. |
| 5 | 반복문 | `for`·`while`·`for...of`로 같은 일을 여러 번 합니다. |
| 6 | 함수 기초 | 코드를 이름 붙은 묶음으로 만들어 다시 씁니다. |
| 7 | 배열 | 여러 값을 목록으로 다루고 `map`·`filter`·`reduce`를 씁니다. |
| 8 | 객체 | 상품·회원처럼 여러 속성을 가진 데이터를 다룹니다. |
| 9 | 문자열 | 문자열 메서드와 템플릿 리터럴로 글자를 다룹니다. |
| 10 | 스코프와 클로저 | 변수가 어디서 보이고 얼마나 오래 사는지 이해합니다. |
| 11 | 오류 처리 | `throw`·`try/catch`로 실패에 대비합니다. |

1~5번은 **재료**(값·계산·흐름 제어), 6~9번은 **묶는 법**(함수·배열·객체·문자열), 10~11번은 **한 단계 깊은 이해**(스코프·오류)입니다. 앞 레슨의 내용을 뒤에서 계속 쓰므로 순서대로 읽기를 권합니다.

## 이 파트를 마치면

- 변수·조건문·반복문·함수로 문제를 단계별로 나누어 코드로 옮길 수 있습니다.
- 배열과 객체로 "상품 목록", "주문 내역" 같은 실무형 데이터를 표현하고 계산할 수 있습니다.
- `==` 대신 `===`, `var` 대신 `const`처럼 실무에서 권장하는 습관을 갖게 됩니다.
- `undefined`·`null`처럼 값이 없을 때를 미리 처리하는 코드를 쓸 수 있습니다.
- VS Code의 빨간 밑줄과 tsc 에러 메시지를 보고 기초 문법 실수를 스스로 고칠 수 있습니다.

## 막히면 이렇게 하세요

1. **예제를 직접 입력해 실행합니다.** 눈으로만 읽으면 이해한 것 같아도 손이 기억하지 못합니다. `npx tsx 파일이름.ts`나 [TS Playground](../part0-start/04-playground)로 바로 돌려 보세요.
2. **값을 찍어 봅니다.** 결과가 이상하면 중간중간 `console.log`로 변수 값을 출력해, 어디서 예상과 달라지는지 찾습니다.
3. **표로 따라가 봅니다.** 반복문이나 조건문이 헷갈리면 종이에 "몇 번째 / 변수 값 / 조건 결과"를 표로 그려 한 줄씩 따라가 보세요. [반복문](./05-loops) 레슨에서 이 방법을 연습합니다.
4. **에러 메시지를 끝까지 읽습니다.** 모르는 메시지는 [에러 메시지 읽는 법](../part0-start/06-how-to-read-errors)의 해석표를 펼쳐 보세요.
5. **연습 문제의 정답을 바로 열지 않습니다.** 10분 이상 고민해도 안 되면 그때 열어 보고, 정답을 본 뒤에는 **안 보고 다시 써 봅니다.**

::: tip 이 파트의 예제 실행 방법
특별한 말이 없으면 예제는 Part 0에서 만든 프로젝트 폴더(예: `ts-study\hello-ts`)에 `.ts` 파일로 저장하고 `npx tsx 파일이름.ts`로 실행합니다. 출력 결과는 `// 출력: ...` 주석이나 별도 블록으로 보여 줍니다. 타입 검사까지 하려면 `npx tsc --noEmit`을 함께 씁니다.
:::
